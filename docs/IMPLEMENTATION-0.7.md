# R6 Camera0.7 功能測試版

本版先交付含模型的離線功能測試。正式100張圖準確度及iPhone持續效能另行驗收，沒有以無模型版本替代鳥眼。

## 鳥眼／鳥頭

- 原始NeoFocus APK內10,802,648 bytes ONNX，SHA256 `350f370aac45ec120bb73434eb0add0446a5f327344c65b03a633229dc2c551b`；原始檔直接封裝，官方ORT Swift1.24.2、CPU兩執行緒。
- RGB／Float32／NCHW／320、灰114正方補邊。全圖、選定鳥身1.2倍ROI、短暫遺失1.7倍搜尋；640CoreML與320ONNX分開契約。
- 新增鳥類選項；鳥類模式略過不必要通用模型。模型在途最多一筆，快速Vision追蹤另有有界佇列。
- 白框候選不指定AF點；觸控選鳥後唯一藍框。SERVO、ONE SHOT、固定點單次AF及MF保留。眼／頭／身體依真實模型點降級，不由鳥身比例虛構眼。
- 模型眼量測時間不由快速追蹤更新，250ms後移除眼細節；遮擋保持焦距，超時解除，拒絕舊世代／序號／時間。缺失事件會使已排隊的快速追蹤失效，不能恢復追焦。
- MENU → AF → 鳥眼模型功能測試：側面、人工遮眼頭部／身體、正面、遠距群鳥、無鳥背景裁切。全部執行實際模型；人工衍生圖不計獨立準確度樣本。

## 穩定連拍與校準操作

1. 選擇所需格式、解析度、鏡頭、曝光、風格、H+／H／L，開啟鳥眼及AF。
2. MENU → 設定 → 連拍穩定速度校準。確認會實際拍照並存檔後，返回取景。
3. 每段按住相機鍵至少10秒，放開後等候已接納照片存檔。再開始下一段；同速度連續三段通過才保存。未滿10秒不計。
4. H+依裝置／格式限制嘗試12／10／8／6／4／2／1，H嘗試6／4／2／1，L1。每檔失敗則降至下一候選，不自動降低畫質、改格式或擷取影片影格。
5. 通過標準：P95間隔偏差≤20%、張數≥90%、中途間隔≤2倍，另檢查起拍及首尾空窗；有降速、存檔失敗、截斷、未完成存檔皆不合格。
6. 單調時鐘固定節拍；不補拍欠帳。同一長按持續受阻才降檔，不回升；壓力上限持久保存，另一次普通長按或重啟不會自行復原。恢復高速須重新校準。
7. 校準依鏡頭、OS、格式、解析度、曝光、縮放／設定及模型身份分開；設定改變或模型失敗中止當次校準。曝光採半級桶，跨桶需重測。
8. MENU → 設定 → 分享最近連拍量測JSON，含請求、didCapturePhoto回呼、處理與App存檔時間。相簿匯出不含在儲存時間中；回呼並非獨立感光元件時間量測。

未校準採H+4／H2／L1保守請求上限，另受曝光／能力及歷史壓力上限限制。這些是請求與校準候選，不是Canon或iPhone硬體張數保證。

## 保留及缺口

保留4:3完整等比取景、影像中心水平儀、圓弧轉盤、原品質策略、曝光／白平衡／風格／回放。拍照僅四邊短白框。音量鍵仍可能觸發快門。

正式100張獨立圖、不可見眼誤報率、手機10Hz／P95≤150ms、實際鏡頭合焦、多鳥身份、熱負載與連拍穩定速度尚需真機資料。遠距群鳥測試有漏檢，不能用固定照片功能通過冒充準確率或持續效能通過。

模型來源與授權證據見[研究紀錄](research/android-bird-0.7.md)，功能封裝門檻見`bird-functional-release.json`；保留模型卡、AGPL及ORT／第三方通知與完整對應來源。
