# iPhone 17 / iOS 27 改版真機驗收

狀態：尚未在真機執行。模擬器 UI 與 CI 編譯成功不能取代本表。

## 實驗性兩段硬體快門（2026-10-23，尚待真機）

MENU → 設定開啟實驗模式；舊設定及首次安裝預設關閉。此模式無法辨別原始按鍵，浮層啟用不是原始半按，浮層關閉也不是鬆開；**授權窗口內音量減仍可能拍攝**。分享硬體快門事件 JSON 保存每組測試，並記錄裝置、OS、實際照片張數；系統若停用輕按手勢，App 無法保證收到浮層代理。

| 場景 | 預期／需記錄 |
| --- | --- |
| 關閉模式、重啟及舊 C1–C3 | 保留既有共用硬體快門；舊資料可讀，新模式關閉 |
| 輕按但不全按 | 只準備對焦，不拍照；分別測 SERVO、ONE SHOT、MF，MF 不驅動 AF，不鎖曝光 |
| 已選主體／固定對焦點／遮擋 | 保留原目標；遮擋時保持焦距，不跳中央或旁人 |
| 輕按後 2 秒內全按 | 單張一張；H+／H／L 按住開始、放開停止，即使持續超過 2 秒仍不自行停止 |
| 直接全按、2 秒後全按 | 不拍攝；需重新關閉再啟用浮層才能授權下一次 |
| 浮層關閉後全按 | 最多保留 300ms，且總期限仍不超過啟用後 2 秒；記錄實際回呼先後與漏判率 |
| 音量加／減短按長按 | 實驗模式音量加不拍；未授權音量減不拍；窗口內音量減可能誤拍，量測但不可當成已解決 |
| 反覆輕按、重複／交錯按鍵 | 一次授權只接受一次開始；重複回呼不重拍、不延長授權、不遺留連拍 |
| A+、滑動切換 AF 模式 | A+ 仍 SERVO，不覆寫原設定；確認停用 picker 時能否啟用浮層，不能則記錄限制並關閉實驗 |
| MENU、回放、設定改變、中斷、背景 | 清除授權並停止連拍；返回後舊事件不得重新放行 |
| 無 controls 支援或註冊失敗 | 顯示限制，實驗快門拒絕放行；關閉實驗可恢復原行為 |
| 系統關閉輕按／調整手勢靈敏度 | 記錄浮層是否仍有事件；不能偵測的手勢不捏造成功 |

若實際浮層事件不能穩定支援先輕按再全按，停用實驗拍攝放行、保留 JSON 與失敗證據。模擬器無法驗收這張表。

## 0.6 試速及定位補充

- 驅動模式→H+，依序8／測試10／測試12→SET；H對應4／6／6。標準速度只在responsive、約24MP以下processed及非精確曝光時提高；高解析度需明確選試速才嘗試10／12。RAW、M／Tv等精確曝光及不支援responsive仍保守限制。**不得為試速改解析度、格式或品質策略**；需要測自動曝光路線時明確切P／A+，不是替使用者偷偷切換。
- 每個配置按住至少10秒，放開後等照片處理完，再到MENU→設定分享最近連拍量測JSON。報告以實際快門回呼量測，含請求／處理／存檔時刻與尺寸，保存原始JSON及成片EXIF；核對P95間隔偏差≤20%、首尾沒有停拍空窗。試速標籤不代表裝置已驗收，失敗時改用較低上限重測並記錄。
- 增加長曝光、RAW、48MP、慢存檔／緩衝滿載組；量測JSON不包含系統相簿匯出時間。若張數多於256導致紀錄截斷，不用該段判定通過。
- INFO顯示水平儀，大／小固定基準都位於4:3影像正中心；活動線可以隨俯仰移動。分開檢查布局中心與感測歸零，不用偏移補償感測方向。
- 鳥眼仍缺合格模型；評分／發布工具通過單元測試不代表辨識通過。權重來源、100張獨立真實鳥圖、多鳥／遠距／遮眼及至少兩種鳥種、iPhone≥10Hz／P95≤150ms仍須實際驗證。

| 場景 | 必須觀察到的結果 |
| --- | --- |
| 首次開啟、拒絕／允許相機 | 拒絕可前往設定；允許可恢復預覽 |
| 冷啟動與裝置旋轉 30 次 | 固定相機鍵在上緣，Island 左、USB-C 右；不反向、不停格、不掛起 |
| Q、MENU、二級選單與回放 | 皆固定同一橫向；回到取景不重新進行可見旋轉 |
| 白框待選 | 最多一個白框；近遠景可基本自動合焦；移動候選框不改變指定對焦座標；無候選不畫框 |
| 點選辨識主體 | 只有一個藍框持續追蹤；鏡頭確實跟隨對焦，能由照片檢查 |
| 點選沒有主體處 | 觸控位置固定藍色正方形，只做一次對焦；後來走入的人不會啟動追焦 |
| 眼睛→頭部→身體 | 降級只針對同一主體，只有一個框，沒有可靠位置不可捏造 |
| 人像轉頭／眼鏡、狗貓 | 真實眼點可追焦；眼睛不見時以觀測頭部／身體降級 |
| 鳥眼／鳥頭（必要但目前缺模型） | 不可將身體偵測冒充通過；待合法可部署模型加入後另行驗收 |
| 鳥、馬、汽車、機車、飛機、火車 | 適當距離／光線下測試實際身體辨識，記錄漏檢與誤檢 |
| 多人交叉、遮擋／離開、解除指定 | 短暫保持焦距；超過寬限退出藍框鎖定、不跳旁人；回到白框與基本自動對焦 |
| 關閉主體／切換 MF 或眼睛設定 | 舊辨識結果不能重新啟動已解除的鏡頭追焦 |
| 左眼／右眼優先 | 指被攝者自己的左右眼，不得和畫面左右混淆 |
| 相機鍵單張、連拍、自拍 | 完全按下拍一張且放開不重拍；連拍放開停止；自拍可取消 |
| H+／H／L 各連拍 10 秒 | 0.5 在 responsive＋processed 請求≤24MP＋非精確曝光時可請求 8／4／1，否則 4／2／1，長曝光另受限；這不是實測保證。不改格式或解析度，記錄每張實際曝光回呼間隔；95% 間隔偏差目標不超過設定間隔 20%，未達標須降速並揭露 |
| 4:3 完整取景與座標 | 中央 4:3，左右 HUD／轉盤不遮取景；原生與風格預覽無額外裁切／拉伸，letterbox 與側邊空白不觸發對焦；四角標記與拍攝檔案逐鏡頭／倍率比較，不能只看比例推論完整 CMOS |
| MF 峰值／放大 | 風格景物底圖仍可見，邊緣輔助疊在同幀上，不退化為黑底輪廓；放大後還原，座標及比例正確 |
| 部分照片回呼／寫檔失敗 | JPEG 或 DNG 單邊失敗時，另一份成功檔保留並可從回放分享；明確報不完整，不冒稱完整 RAW 拍攝成功 |
| 長曝光、RAW、緩衝滿載、慢速存檔 | 清楚顯示忙碌／降速，不靜默漏請求、不事後快速補拍；放開立即停止新增請求 |
| 自拍連拍 | 10 秒倒數後拍指定 2–10 張；取消後不再新增拍攝 |
| MENU／回放期間按相機鍵 | 不意外拍照，不恢復已取消的連拍 |
| 拍攝即時回饋 | 不疊照片、不主動暫停預覽；四邊白框約120ms後淡出，連拍逐張提示 |
| 音量上下鍵（API區分尚未解決） | 必須各自按下／放開均不拍照，且相機鍵仍拍照，方可宣稱只有相機鍵 |

| 螢幕轉盤與捏合 | 固定黃色指針，整盤跟手；逆時針放大、順時針縮小，高倍率在上；跨角度邊界不跳動，實際倍率同步，文字與刻度不裁切 |
| 切換鏡頭、鎖鏡頭 | 保持同一方向與對焦座標；鎖定模式下裁切行為清楚 |
| A+／P／Tv／M／Fv 與 AUTO 切換 | A+ 自動且不覆寫原本設定，P 允許調 WB／風格／AF，Tv 保持快門，M 的 ISO AUTO 不切離 M，Fv 可獨立 AUTO；成片 EXIF 與實際裝置回報一致 |
