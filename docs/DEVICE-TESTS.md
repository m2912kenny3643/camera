# iPhone 17 / iOS 27 真機驗收

狀態：尚未在真機執行。不得以模擬器或 CI 編譯成功取代本表。

| 場景 | 必須觀察到的結果 |
| --- | --- |
| 首次開啟、拒絕／允許相機 | 拒絕可前往設定；允許可恢復預覽 |
| 單拍按鍵、連拍按住／放開 | 單拍一張、不重複；連拍停止後不再提交新請求 |
| 原生 Camera Control 滑動 | 真正改變倍率，畫面數字同步；控制浮層可以正常開關 |
| 原生縮放、捏合、0.5/1/2× 切換 | 不跳回過時倍率，鎖鏡頭選項行為可辨認 |
| 人像正面、側面、戴眼鏡、轉頭 | 框隨主體；只在有真實眼睛定位時顯示眼框 |
| 狗、貓 | 可靠眼點可追焦；眼點消失降級身體 |
| 鳥、馬、汽車、機車、飛機、火車 | 在合適距離／光線識別主體；不捏造眼睛 |
| 多人同框、點選、旁人穿越、短暫遮擋 | 鎖定框不任意跳旁人；目標失去時明示狀態 |
| 左眼／右眼優先 | 指被攝者自身左右眼；不得螢幕左右顛倒 |
| 鎖定主體向鏡頭走近 | 不只畫框移動，鏡頭焦距也跟隨，照片銳利度可檢查 |
| 遮住鏡頭／低照度 | 不能保證綠框等於合焦；失敗可重新點選 |
| 橫向左右、直向旋轉 | 預覽不倒轉；框、眼點、點選與 AF 位置一致 |
| Tv、M、Fv 的不同組合 | 成片 EXIF 與裝置回報值一致；超出範圍清楚夾限 |
| MF、3× 顯示、邊緣輔助 | 顯示放大不改變成片倍率；手動焦距確實改變 |
| HEIF/JPEG 與可用 RAW 配置 | 檔案可開啟、方向正確；DNG 不套風格 |
| 各風格、白平衡、色溫 | 預覽與成片趨勢一致；EXIF 曝光資料仍在 |
| 拒絕相簿權限、相簿寫入失敗 | App 內照片保留且可分享，不回報假儲存成功 |
| 自拍取消、背景／前景、來電中斷 | 不在背景意外拍照；恢復前景後可繼續使用 |
| C1–C3、重啟 App | 參數可重現，包括主體／眼睛／風格／倍率 |
| 持續使用 10 分鐘 | 無推論請求堆積、記憶體持續上升或明顯 UI 卡死 |

請記錄 iOS 完整版本、鏡頭、光線、EXIF、失敗照片與實際測試結果。
