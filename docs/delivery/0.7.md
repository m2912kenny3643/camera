## 使用

相機主體選「鳥類」、眼睛自動、SERVO。觸控前基本AF＋白色候選框；點鳥後唯一藍框依眼／頭／身體降級。ONE SHOT與MF保持不同鏡頭策略。縮放／重新選取／遮擋失效後，排隊中的舊結果不能恢復追焦；眼量測超過250ms沒有校正即移除細節。

MENU→AF→鳥眼模型功能測試，可查看離線固定圖的實際結果與匯出本張JSON。遠距群鳥確有漏檢，眼點位置仍需正式評分。

連拍以一致節奏優先，同次長按僅持續受阻時降檔，不回升、不補拍欠帳；降速限制跨長按與重啟保存。MENU→設定→連拍穩定速度校準，會先明示實際拍照與存檔。建議在鳥眼開啟並選定鳥的負載下，每段長按至少10秒，連續三段通過才按配置保存。候選H+12/10/8/6/4/2/1、H6/4/2/1、L1，依格式／曝光／硬體能力限制；未校準保守H+4/H2/L1。詳細操作與合格門檻見[實作及操作說明](../IMPLEMENTATION-0.7.md)。
